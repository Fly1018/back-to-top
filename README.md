# Back to Top

A small SiYuan desktop plugin that adds a floating "back to top" button to the editor.

- The button fades in after the active editor is scrolled more than 300 px.
- Clicking it smoothly scrolls the current document to the top.
- It follows the active editor across tabs, splits, and dock resizing.
- No settings, no note data access, no network requests.

Rebuilt with Vite 8 + TypeScript + Svelte 5.

## Development

```bash
pnpm install
pnpm dev
pnpm check
pnpm build
```
